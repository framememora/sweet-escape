# sweet-escape

Website for **The Sweet Escape**, a dessert shop in Kochi (Thoppumpady & Fort Kochi). [Instagram](https://www.instagram.com/the_sweet_escapenew_/)

A static site (HTML, CSS and vanilla JS) with no build step.

## Run locally

```
python -m http.server 8765
```

Then open http://localhost:8765.

## Before launch

- Set the real WhatsApp number in `WHATSAPP_NUMBER` at the top of `script.js` (it's currently a placeholder).
- Replace the stand-in photos in `images/` with the shop's own photos. See `images/README.md` and `images/CREDITS.md`.
- Add the Fort Kochi opening hours to `index.html`.
- Have the Privacy Policy (`privacy.html`) and Terms of Service (`terms.html`) reviewed.
